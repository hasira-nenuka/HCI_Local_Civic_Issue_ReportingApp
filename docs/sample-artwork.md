# Sample dataset artwork

Generated with the built-in imagegen tool and visually inspected. All assets are bundled locally; no Firebase Storage or remote image service is required. Category detail illustrations use the existing reduced-motion-aware floating animation. Portraits are fictional illustrations, and four portrait styles are reused across the sample accounts.

## Prompt template

`Square mobile UI asset for Citizen Connect: {subject}. Premium soft 3D cartoon illustration, charming smooth rounded shapes, professional civic app visual. Royal blue #1769df anchors the palette, restrained mint and warm amber accents. Centered uncluttered subject fills 75 percent of square, generous outer margins, soft studio lighting, crisp clean details. No lettering, no numbers, no text, no watermark. Entirely fictional illustration.`
